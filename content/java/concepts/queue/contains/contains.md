# Description of .contains()

In Java, the **`.contains()`** method checks whether a string contains a specific sequence of charaters (substring) exists within a given string. This method is case-sensitive and the return is a boolean. If the string or substring is found (exists), it returns `true`. If it is not found (does not exist), it returns `false`.

## Syntax

```
public boolean contains()
```
